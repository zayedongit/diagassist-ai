Reading the chart types

ROC / AUC — true-positive vs false-positive trade-off; area 0.5 random → 1.0 perfect.   Confusion matrix — correct vs incorrect calls (diagonal = right).   Reliability curve / Brier — are probabilities honest? on-diagonal = yes, lower Brier = better.   Precision-recall / AP — positive-class quality.   Learning curve — small train↔CV gap = low overfitting; plateau = more data won't help.   Permutation importance — score drop when a feature is shuffled.
